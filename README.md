# できること
簡易的な路線図（二種類の重みがついた無向グラフ）が与えられるとき，出発地と到着地の駅名を決めるとその二つの駅の間の最短経路と最低賃金経路を（路線が一致しているところを一つにまとめて）返すプログラム．

## 使い方
makeでコンパイルして./testで実行する．
実行すると"from>"が出力されるのでそこに出発駅を入力する．
次に"to>"が出力されるので到着駅も入力．
最後に最短経路か最低賃金経路かを問われるので最短経路なら"0"，最低賃金経路なら"1"を入力する．

二つの駅の一方が存在しなかったり，たどり着く方法がなかったりする場合はその旨を出力で伝えて入力をやり直す
任意の入力で"exit"またはctrl+Cでプログラム終了

connection.csvは一行目はfrom,to,line,fare,timeで二行目以降には路線図の駅間の路線，運賃，移動時間を羅列する

git clone ...
cd route
./src/main

## 注意
プログラム実行中の駅名の入力は空白や改行を含んではならない
connection.csvの駅名なども空白を含んではならない(改行は含んでいてもよい)
connection.csvの一行目はfrom,to,line,fare,time以外は不可
運賃(fare)とtime(時間)は合計が1e9を越えないようにする必要がある（int型で計算しているため）
