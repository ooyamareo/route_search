# Route Search

路線図を重み付き無向グラフとして表現し，ダイクストラ法を利用して最短経路および最低運賃経路を探索する C++ プログラムです。

## 概要

路線図を無向グラフとして扱い、出発駅と到着駅を指定すると

- 最短経路（時間最小）
- 最低運賃経路

を探索するプログラムです。

同一路線を連続して利用する区間はまとめて表示します。

## ビルド

```bash
make
```

## 実行

リポジトリのルートディレクトリで実行してください。

```bash
./test
```

実行後、

```text
from>
```

が表示されるので出発駅名を入力します。

続いて

```text
to>
```

が表示されるので到着駅名を入力します。

最後に

```text
0 : 最短経路
1 : 最低運賃経路
```

から選択します。

## 終了方法

- `exit` を入力
- `Ctrl+C`

## 入力データ

`data/connection.csv`

形式:

```csv
from,to,line,fare,time
A,B,JR,170,3
B,C,JR,150,2
...
```

| 列名 | 内容 |
|------|------|
| from | 出発駅 |
| to | 到着駅 |
| line | 路線名 |
| fare | 運賃 |
| time | 移動時間 |

## 実行例
```text
./test
from>大阪
to>木津

最短経路(2260円,34分)
大阪

|
京田辺

```

## 制約

- 駅名・路線名に空白を含めない
- ヘッダ行は `from,to,line,fare,time` 固定
- 運賃と時間の合計は `10^9` 以下

## エラー処理

以下の場合はエラーメッセージを表示し、再入力を求めます。

- 存在しない駅名を入力した場合
- 到達不能な駅を指定した場合
